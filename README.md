# PassGen
# EN
Desktop app for generating strong passwords locally, with variation suggestions based on themes you like.

A simple and straightforward desktop app that creates strong random passwords without relying on an internet connection. It also helps turn a topic or word you like into multiple password options — everything is processed directly on your own device.

Features
Random passwords from 5 to 24 characters, with control over uppercase letters, lowercase letters, numbers, and symbols.
Password strength indicator for generated passwords.
Dark mode, with the preference remembered between sessions.
Local variations: starting from a word or base password, the app generates different options using leet speak, uppercase letters, and symbols — all processed locally in the browser, with nothing sent over the network.
Topic-based references: enter a topic you're interested in, and the app suggests related words that can be used as the basis for a password.
About the "Topic-Based References" Feature

This feature uses an AI model to find words associated with a given topic, or alternatively uses the Wikipedia and MuseData APIs. It works normally with these options, but it is more useful when connected to the Artifact API.

# PT-BR

Gerador de senhas seguras rodando localmente, com variações a partir de temas de interesse.

App de desktop simples e direto: cria senhas aleatórias fortes sem depender de internet, e ajuda a transformar um tema ou palavra que você gosta em várias opções de senha — tudo processado no seu próprio dispositivo.

Funcionalidades

Senhas aleatórias de 5 a 24 caracteres, com controle sobre maiúsculas, minúsculas, números e símbolos.
Indicador de força da senha gerada.
Modo escuro, com preferência lembrada entre usos.
Variações locais: a partir de uma palavra ou senha-base, gera opções misturando leet-speak, maiúsculas e símbolos — tudo processado no navegador, nada enviado pela rede.
Referências por tema: digite um assunto que você goste e o app sugere palavras associadas pra usar como base de uma senha 

Sobre a feature "Referências por tema"

Essa parte pergunta a um modelo de IA por palavras associadas a um tema digitado ou para a api da Wikipedia e Musedata. Ela funciona normalmente mas possui mais utilidade conectando a api da Artifact.
